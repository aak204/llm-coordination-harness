## Empirical Result

### Leaf Attack Across 4 Topologies

Live slice:

- model: `gemini31_flash_lite_preview`
- budget: `96`
- baseline: `ma_ft`
- benchmarks: `CRAFT-mini`, `AgentsNet-mini`
- seeds: `7`, `11`

Mean results:

- `linear_chain`: `quarantine_strength = 1.0`, `F_delta_vs_clean = 0.016667`, `score_delta_vs_clean = 0.125`
- `balanced_tree`: `quarantine_strength = 0.859375`, `F_delta_vs_clean = 0.125`, `score_delta_vs_clean = 0.125`
- `star`: `quarantine_strength = 0.8125`, `F_delta_vs_clean = 0.5625`, `score_delta_vs_clean = -0.125`
- `complete_graph`: `quarantine_strength = 0.8125`, `F_delta_vs_clean = 0.5625`, `score_delta_vs_clean = -0.125`

Ordering under leaf attack:

- best containment: `linear_chain`
- second: `balanced_tree`
- worst and tied: `star`, `complete_graph`

### Balanced Tree: Leaf vs Middle Manager

Balanced-tree means:

- `leaf`: `quarantine_strength = 0.859375`, `F_delta_vs_clean = 0.125`, `score_delta_vs_clean = 0.125`
- `middle_manager`: `quarantine_strength = 0.84375`, `F_delta_vs_clean = 0.0`, `score_delta_vs_clean = 0.0`

Interpretation:

- attacking a middle manager in `balanced_tree` slightly weakens quarantine relative to leaf attack
- but it does not degrade `F` in the same way the leaf attack does
- in the current benchmark pack, the manager attack does not produce a stronger score collapse than the leaf attack

### Correlation Result

For the `leaf` slice across the topology zoo:

- `pearson_r = 0.837219`
- `linear_slope = 0.273803`
- `n = 16`

This is a strong positive relation between `F_delta_vs_clean` and `infection_spread_rate`.

Meaning:

topologies that lose more useful fact flow also tend to spread the infection more, not less.

## Main Takeaway

`v0.3.0` does not support a general "natural quarantine by degradation" law.

The cleaner statement supported by the data is:

- `balanced_tree` is better than `star` under leaf attacks
- `linear_chain` is even more containment-friendly under the current rooted-fusion protocol
- `complete_graph` behaves essentially like `star` in this harness because rooted aggregation collapses its extra edges into a star-like fan-in effect
- degrading useful coordination is not buying robustness here; the higher-`F` topologies are also the safer ones
