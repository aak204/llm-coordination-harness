## Main Outcome

The predictor fits the seen model family surprisingly well:

- in-sample MAE `0.011333`

But on frontier hold-outs it is much worse:

- OOD MAE `0.120872`
- OOD MAE `0.11304` on `GPT-5.4`
- OOD MAE `0.506112` on `Gemini 3.1 Pro Preview`

The direction of the failure is informative:

- the predictor systematically overestimates vulnerability for `GPT-5.1` and `GPT-5.4`
- especially on `Star`, where the model remained much more resilient than expected
- on `Linear Chain`, the model achieved zero observed spread while the predictor still assigned nonzero expected vulnerability
- for `Gemini 3.1 Pro Preview`, the failure flips: the predictor strongly underestimates vulnerability across both `Star` and `Linear Chain`

This means the predictor is learning a useful structural prior, but it is not yet model-universal.

## Scientific Reading

What is supported:

- clean physics (`F, rho, B, C`) contain real predictive signal for vulnerability
- `C` is the dominant empirical feature in the current dataset
- topology-driven vulnerability remains a strong prior

What is not yet supported:

- a model-agnostic universal predictor that transfers cleanly to frontier SOTA systems

The OOD result suggests that strong frontier models may internally compensate for vulnerabilities in ways not captured by the current clean feature basis.

## Release Assessment

Engineering status:

- boosting pipeline: complete
- clean-control completion for v0.4: complete
- frontier clean/stress OOD protocol: complete
- release reporting: complete

Scientific status:

- predictor exists and is accurate on seen distributions
- transfer to `GPT-5.x` is promising but still imperfect
- transfer to `Gemini 3.1 Pro Preview` fails badly
- universality claim is therefore not earned
- v1.0.0 should be framed as an RC with a successful predictor prototype and a failed strong-universality test
