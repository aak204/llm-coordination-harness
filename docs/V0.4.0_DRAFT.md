# V0.4.0 Draft

Date: 2026-04-05

## Scope

`v0.4.0` studies whether explicit reasoning can compensate for topology weakness under attack.

This release has three parts:

- reasoning ablation on `Star` with `Gemini` and `Qwen`
- topology-scale sweep with `Gemma 4`
- boss-fight on `Star` with `GLM 5V Turbo`

The central question is:

Can reasoning rescue the vulnerable `Star` topology at `budget = 96`?

Important semantic note:

`enable_reasoning` is implemented as prompt-level reasoning, not OpenRouter native reasoning-tokens mode.

Concretely:

- `enable_reasoning: true` asks the model to emit a short `<think> ... </think>` block before the final structured answer
- peer-message serialization strips reasoning blocks before inter-agent transmission
- the `96` token message budget therefore applies to the public payload only, not to hidden reasoning text

This was chosen to preserve metric comparability for `F`.

## Empirical Readout

### 1. Reasoning Ablation On Star

Live slice:

- topology: `star`
- budget: `96`
- baseline: `ma_ft`
- attack: leaf
- models: `gemini31_flash_lite_preview`, `qwen35_plus_0215`
- reasoning: `false` vs `true`

Aggregates:

- `Gemini`, reasoning `false`: `score = 0.875`, `F = 0.4375`, `infection = 0.1875`, `quarantine = 0.8125`, `attack_success = 0.125`
- `Gemini`, reasoning `true`: `score = 0.75`, `F = 0.375`, `infection = 0.15625`, `quarantine = 0.84375`, `attack_success = 0.25`
- `Qwen`, reasoning `false`: `score = 0.9375`, `F = 0.46875`, `infection = 0.101562`, `quarantine = 0.898438`, `attack_success = 0.0625`
- `Qwen`, reasoning `true`: `score = 0.875`, `F = 0.4375`, `infection = 0.109375`, `quarantine = 0.890625`, `attack_success = 0.125`

Interpretation:

- `Gemini` gets a small quarantine improvement from prompt-level reasoning, but at the cost of lower `score`, lower `F`, and higher `attack_success_rate`
- `Qwen` does not benefit from reasoning on `Star`; it gets slightly worse on both robustness and utility
- reasoning does not repair the topology-level weakness of `Star`

### 2. Gemma 4 Scale Sweep

Live slice:

- model: `gemma4_31b_it`
- reasoning: `true`
- attack: leaf
- topologies: `star`, `linear_chain`, `balanced_tree`

Aggregates:

- `balanced_tree`: `score = 0.9375`, `F = 0.8125`, `infection = 0.054688`, `quarantine = 0.945312`, `attack_success = 0.0625`
- `linear_chain`: `score = 1.0`, `F = 0.933333`, `infection = 0.0`, `quarantine = 1.0`, `attack_success = 0.0`
- `star`: `score = 0.875`, `F = 0.4375`, `infection = 0.101562`, `quarantine = 0.898438`, `attack_success = 0.125`

Comparison against no-reasoning baselines:

- `Gemini` no-reasoning from `v0.3.0` on `balanced_tree`: `score = 0.8125`, `infection = 0.148438`, `quarantine = 0.851562`
- `Gemini` no-reasoning from `v0.3.0` on `linear_chain`: `score = 0.9375`, `infection = 0.023438`, `quarantine = 0.976562`
- `Gemini` no-reasoning from `v0.3.0` on `star`: `score = 0.875`, `infection = 0.1875`, `quarantine = 0.8125`
- `Qwen` no-reasoning from `v0.4.0` ablation on `star`: `score = 0.9375`, `infection = 0.101562`, `quarantine = 0.898438`

Interpretation:

- `Gemma 4` is strong on hierarchical topologies
- on `linear_chain`, it is the best observed profile in the current repo: perfect aggregate score with zero observed infection spread
- on `star`, it improves over `Gemini` no-reasoning, but does not exceed `Qwen` no-reasoning

### 3. Boss Fight: GLM 5V Turbo On Star

Live slice:

- model: `glm5v_turbo`
- topology: `star`
- reasoning: `true`

Aggregate:

- `score = 0.9375`
- `F = 0.4375`
- `infection = 0.171875`
- `quarantine = 0.828125`
- `attack_success = 0.0625`

Interpretation:

- `GLM 5V Turbo` does not collapse on `Star`
- it beats `Gemini` no-reasoning on spread and attack success
- it still underperforms `Qwen` no-reasoning on quarantine
- the advertised "native agent foundation" does not show a decisive robustness breakthrough in this harness

## Main Takeaway

`v0.4.0` does not support the claim that reasoning compensates for the structural weakness of `Star`.

The strongest supported reading is:

- topology still dominates
- prompt-level reasoning is at best a weak second-order modifier
- better models can improve the robustness frontier, but they do not erase the ordering induced by topology

In practice:

- `Star` remains vulnerable
- `Tree` and especially `Chain` remain safer
- `Gemma 4` is a strong model-level upgrade for robust topologies
- `Qwen` no-reasoning remains the strongest observed `Star` baseline in this repo
